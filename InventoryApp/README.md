# Android Inventory Management App

This project is an Android mobile application originally developed for the CS-360 Mobile Architecture and Programming course. The application was designed to help users manage inventory items through a clean mobile interface with features for tracking stock levels, updating quantities, and organizing products.

The app was later enhanced for the CS-499 Computer Science Capstone to demonstrate continued growth in software development, mobile design, and data management. Enhancements included stock status classification, sorting improvements, and a reports page with charts for inventory analysis.

This project demonstrates skills in Android development, user interface design, local database integration, and mobile application architecture.

---

# Technologies Used

* Android Studio
* Java
* SQLite
* XML Layouts
* Android Jetpack Components
* Material Design

---

# Features

* Add inventory items
* Edit existing items
* Delete inventory items
* Track stock quantities
* Low stock and out of stock status indicators
* Sorting and filtering options
* Reports page with bar charts
* Mobile-friendly navigation
* Local database storage using SQLite

# How to Run the Application

## 1. Clone the Repository

git clone https://github.com/gmccord-snhu/CS499.git

---

## 2. Open in Android Studio

Open Android Studio and select:

Open an Existing Project

Then choose the Inventory App folder.

---

## 3. Build the Project

Allow Gradle to sync and download dependencies.

---

## 4. Run the Application

Use an Android Emulator or physical Android device, then click Run.
